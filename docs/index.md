# 火箭航电系统文档

本项目是一个面向实验火箭的自主航电系统，涵盖飞行计算机、姿态与导航传感器、遥测通信、数据记录、飞行状态管理、地面站以及相关机械结构。

本网站用于记录项目的设计方案、软件架构、硬件实现、测试过程和技术决策，并作为项目长期维护和知识传承的技术文档。

---

## 项目概述

当前航电系统以 STM32F411 为主控制器，主要包括：

* **主控制器**：STM32F411
* **惯性测量单元**：BMI088
* **卫星导航模块**：u-blox NEO-M9N
* **无线遥测模块**：SX1268 LoRa
* **外部存储器**：W25Q128 Flash
* **实时操作系统**：FreeRTOS
* **主要开发语言**：C / C++
* **构建系统**：CMake + Ninja
