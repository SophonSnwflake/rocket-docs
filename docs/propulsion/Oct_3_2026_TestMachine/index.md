# Oct_3_2026 试车台

本次试车台用于试验在2026年10月3日河南新乡所用火箭的发动机。

## 设计者：白

## 硬件设计：

- Arduino uno
- HX711-UART模块
- SD卡槽-UART模块
- 串口通信
