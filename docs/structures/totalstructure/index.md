# 舰体结构

记录火箭整体机械结构各部件的三维模型（STEP 格式），涵盖箭体、头锥、尾翼、发动机舱、航电舱、伞舱以及各连接环等部件。

|------|----------|

| 头锥 | [头锥111.step](assets/头锥111.step) |

| 中心环 | [中心环.step](assets/中心环.step) |

## 说明

* 模型采用 STEP 格式（ISO 10303），适用于主流三维 CAD 软件（如 SolidWorks、Fusion 360、FreeCAD 等）。
* 各部件模型将随设计迭代持续更新。
